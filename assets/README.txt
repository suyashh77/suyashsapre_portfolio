Assets Folder for Portfolio
============================

Place your files here:

1. profile.jpg
   - Recommended size: 400x500px or similar aspect ratio
   - Will be displayed in a rounded frame with gradient border
   - If missing, a placeholder will show

2. resume.pdf
   - Your resume in PDF format
   - Linked from the "Download Resume" button on the homepage
   - Also available from navigation on all pages

To add your files:
- Simply copy your image to this folder and name it "profile.jpg"
- Copy your resume PDF to this folder and name it "resume.pdf"
