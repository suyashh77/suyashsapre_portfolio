WolfAttend

A smart attendance tracking system designed for NC State that combines cryptographic one-time codes (TOTP) with passive campus WiFi RADIUS validation to deliver verified, cheat-resistant attendance in under 15 seconds — with zero hardware and no new student apps. Proposal submitted to NC State OIT and DELTA with active institutional feedback received.

Key Design Elements
  • TOTP-based session codes — unique, time-bound, never reusable
  • Passive RADIUS validation via Cisco ISE pxGrid — no new tracking infrastructure
  • Blocks remote submissions, VPN spoofing, code sharing, and replay attacks
  • No student is ever auto-marked absent — flagged records go to instructor review
  • Zero hardware, zero student app installs, near-zero ongoing cost
  • FERPA-compliant — minimal data collection, all on university infrastructure
Systems Design Moodle Plugin TOTP / RFC 6238 Cisco ISE pxGrid API FERPA

YouTube Notes Taker

Automated pipeline that monitors a YouTube playlist, transcribes new videos using YouTube captions (with local Whisper as fallback), and generates structured AI-powered summaries with key takeaways, detailed notes, and action items — all on a daily schedule.

Features
  • Playlist monitoring and automatic new video detection via yt-dlp
  • YouTube captions with local Whisper fallback — no transcription API costs
  • Structured markdown summaries with key takeaways, notes, and action items
  • Per-video API cost tracking in Excel
  • Idempotent and fault-tolerant — safe to re-run, failed videos retry automatically
  • Schedulable via Windows Task Scheduler or cron
